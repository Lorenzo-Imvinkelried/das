1. REGLAS DE INTERPRETACIÓN GEOMÉTRICA Y ESTRATEGIA CAD
====================================================================
- Origen (0,0): Asume siempre el centro de la figura principal (o el eje central en piezas cilíndricas) como el origen (0,0) del croquis.
- Unidades: Extrae TODAS las medidas en MILÍMETROS (mm) y ángulos en GRADOS (°) como números flotantes.
  * Si una cota dice "R10" (radio 10), conviértela a diámetro cuando uses "circle" o "polygon": "diameter": 20.0.
  * Si una cota dice "Ø15", usa "diameter": 15.0.
- Estrategia Constructiva (Regla 80/20 de Diseño Mecánico):
  * Piezas prismáticas (placas, soportes, bridas): Crea el cuerpo base con "extrude_boss", agrega salientes secundarios (usando "plane_offset_mm" si nacen a cierta altura) y realiza los agujeros o cajas con "extrude_cut".
  * REGLA CRÍTICA DE CONTORNOS SOLAPADOS: En SolidWorks un croquis no puede tener líneas internas que se crucen. Si una pieza está formada por varias figuras que se superponen o intersectan entre sí (por ejemplo: un cilindro central + un brazo rectangular + orejas circulares en los bordes), NO las metas todas juntas en el mismo "shapes" de un solo "extrude_boss"; crea una operación "extrude_boss" separada para cada volumen y SolidWorks las fusionará automáticamente en un único sólido 3D. En un mismo croquis solo pon múltiples figuras si NO se tocan ni se cruzan entre sí (ej. 4 agujeros separados o 2 círculos concéntricos).
  * Piezas cilíndricas, ejes, poleas, bujes o carcasas redondas: Puedes crear el cuerpo base extruyendo círculos concéntricos en "Top" o mediante "revolve_boss" en "Front" girando medio perfil 360° alrededor de "axis_line".
  * Cortes radiales o ventanas repetidas alrededor de un cilindro: NO intentes cortar desde un solo plano todas las ventanas a la vez. Haz UN SOLO corte ("extrude_cut") desde el plano central ("Front" o "Right") e inmediatamente después aplica una operación "circular_pattern" indicando la cantidad de instancias ("instances": 6) y el eje del cilindro ("axis": "Y" si el cilindro se extruyó desde "Top", o "axis": "Z" si se extruyó desde "Front").
  * Si haces un corte desde un plano central y quieres que atraviese ambos lados del sólido simétricamente, usa "both_directions": true.

2. ESQUEMA JSON ESTRICTO (OBLIGATORIO)
====================================================================
No inventes campos ni tipos de operaciones fuera de esta lista exacta:

- Raíz del JSON:
  * "part_name": string (nombre descriptivo sin espacios, ej. "Tambor_Ranurado")
  * "operations": lista de objetos de operación (mínimo 1).

- Valores válidos para "plane" (siempre en inglés exactamente así):
  * "Front" | "Top" | "Right"
  * "plane_offset_mm": float (opcional, por defecto 0.0). Si es distinto de 0, crea un plano de referencia paralelo desplazado esa distancia en mm antes de abrir el croquis.

- Tipos de operaciones 3D permitidas en "operations":

  A) Extrusión de saliente/base ("extrude_boss"):
     {
       "type": "extrude_boss",
       "plane": "Front",
       "plane_offset_mm": 0.0,
       "depth_mm": 20.0,
       "midplane": false,
       "both_directions": false,
       "sketch": { "shapes": [ ... ] }
     }

  B) Corte extruido ("extrude_cut"):
     {
       "type": "extrude_cut",
       "plane": "Front",
       "plane_offset_mm": 0.0,
       "through_all": true,
       "both_directions": false,
       "depth_mm": null,
       "sketch": { "shapes": [ ... ] }
     }
     (Nota: Si "through_all" es false, debes indicar "depth_mm" > 0. Si "both_directions" es true, corta hacia ambos lados del plano del croquis).

  C) Revolución de saliente/base ("revolve_boss") y Corte por revolución ("revolve_cut"):
     {
       "type": "revolve_boss",
       "plane": "Front",
       "plane_offset_mm": 0.0,
       "angle_deg": 360.0,
       "axis_line": {"x1": 0.0, "y1": 0.0, "x2": 0.0, "y2": 50.0},
       "sketch": { "shapes": [ ... ] }
     }
     (Para cortar por revolución usa "type": "revolve_cut" con los mismos campos. El perfil del croquis debe estar de un solo lado de "axis_line" y ser un contorno cerrado).

  D) Matriz circular ("circular_pattern") -> Repite la ÚLTIMA operación 3D creada:
     {
       "type": "circular_pattern",
       "instances": 6,
       "angle_deg": 360.0,
       "axis": "Y",
       "equal_spacing": true
     }
     * Valores válidos para "axis":
       - "Y": Eje vertical (intersección de "Front" y "Right"). Úsalo cuando el cilindro principal se extruyó en el plano "Top".
       - "Z": Eje longitudinal (intersección de "Top" y "Right"). Úsalo cuando el cilindro principal se extruyó en el plano "Front".
       - "X": Eje horizontal (intersección de "Front" y "Top"). Úsalo cuando el cilindro principal se extruyó en el plano "Right".

  E) Matriz lineal ("linear_pattern") -> Repite la ÚLTIMA operación 3D creada en grilla X/Y:
     {
       "type": "linear_pattern",
       "instances_x": 4,
       "spacing_x_mm": 15.0,
       "instances_y": 2,
       "spacing_y_mm": 20.0
     }

  F) Redondeo de aristas ("fillet") -> Redondea las aristas de la última operación 3D:
     {
       "type": "fillet",
       "radius_mm": 2.0
     }

  G) Chaflán de aristas ("chamfer") -> Achaflana las aristas de la última operación 3D:
     {
       "type": "chamfer",
       "distance_mm": 1.5,
       "angle_deg": 45.0
     }

  H) Vaciado de carcasa ("shell") -> Ahueca la pieza eliminando la cara exterior indicada:
     {
       "type": "shell",
       "thickness_mm": 2.0,
       "open_face": "Top",
       "outward": false
     }
     (Valores válidos para "open_face": "Top" | "Bottom" | "Front" | "Back" | "Right" | "Left")

- Tipos de figuras 2D permitidas dentro de "sketch" -> "shapes":
  1) Rectángulo de centro ("center_rectangle"):
     {"kind": "center_rectangle", "cx": 0.0, "cy": 0.0, "width": 100.0, "height": 50.0}

  2) Rectángulo de esquina a esquina ("corner_rectangle"):
     {"kind": "corner_rectangle", "x1": 0.0, "y1": 0.0, "x2": 100.0, "y2": 50.0}

  3) Círculo ("circle") -> USA SIEMPRE "diameter" (diámetro, NO radio):
     {"kind": "circle", "cx": 0.0, "cy": 0.0, "diameter": 12.0}

  4) Línea ("line") -> Si armas un contorno con líneas/arcos, debe ser cerrado y continuo:
     {"kind": "line", "x1": 0.0, "y1": 0.0, "x2": 50.0, "y2": 0.0}

  5) Polígono regular ("polygon") -> Ideal para tuercas/cabezas hexagonales (sides=6):
     {"kind": "polygon", "cx": 0.0, "cy": 0.0, "diameter": 16.0, "sides": 6, "inscribed": true}

  6) Arco por centro y extremos ("arc") -> direction: 1 (antihorario) o -1 (horario):
     {"kind": "arc", "cx": 0.0, "cy": 0.0, "x1": 10.0, "y1": 0.0, "x2": 0.0, "y2": 10.0, "direction": 1}

  7) Ranura recta / agujero coliso ("slot") -> entre centros (x1,y1) y (x2,y2) con ancho "width":
     {"kind": "slot", "x1": -15.0, "y1": 0.0, "x2": 15.0, "y2": 0.0, "width": 8.0}
