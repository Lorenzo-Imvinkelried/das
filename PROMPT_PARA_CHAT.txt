1. REGLAS DE INTERPRETACIÓN GEOMÉTRICA
====================================================================
- Origen (0,0): Asume siempre el centro de la figura principal (o la esquina inferior izquierda si es asimétrica) como el origen (0,0) del croquis.
- Unidades: Extrae TODAS las medidas en MILÍMETROS (mm) como números flotantes.
  * Si una cota dice "R10" (radio 10), conviértela siempre a diámetro: "diameter": 20.0.
  * Si una cota dice "Ø15", usa "diameter": 15.0.
- Estrategia Constructiva:
  * Paso 1: Crea siempre el volumen principal primero usando "extrude_boss".
  * Paso 2: Agrega salientes secundarios con "extrude_boss" si existen.
  * Paso 3: Realiza todos los agujeros, perforaciones y rebajes usando "extrude_cut".
- Si en el dibujo no figura el espesor de extrusión y no lo especifiqué abajo, asume "depth_mm": 5.0.
- Si los agujeros parecen atravesar toda la placa, usa "through_all": true.

2. ESQUEMA JSON ESTRICTO (OBLIGATORIO)
====================================================================
No inventes campos ni tipos de operaciones fuera de esta lista exacta:

- Raíz del JSON:
  * "part_name": string (nombre descriptivo sin espacios, ej. "Soporte_Motor")
  * "operations": lista de objetos de operación (mínimo 1).

- Valores válidos para "plane" (siempre en inglés exactamente así):
  * "Front" | "Top" | "Right"

- Tipos de operaciones permitidas en "operations":
  A) Extrusión de saliente/base (agrega material):
     {
       "type": "extrude_boss",
       "plane": "Front",
       "depth_mm": 8.0,
       "midplane": false,
       "sketch": {
         "shapes": [ ... ]
       }
     }

  B) Corte extruido (quita material):
     {
       "type": "extrude_cut",
       "plane": "Front",
       "through_all": true,
       "depth_mm": null,
       "sketch": {
         "shapes": [ ... ]
       }
     }
     (Nota: Si "through_all" es false, debes indicar un número > 0 en "depth_mm").

- Tipos de figuras 2D permitidas dentro de "sketch" -> "shapes":
  1) Rectángulo de centro ("center_rectangle"):
     {"kind": "center_rectangle", "cx": 0.0, "cy": 0.0, "width": 100.0, "height": 50.0}

  2) Rectángulo de esquina a esquina ("corner_rectangle"):
     {"kind": "corner_rectangle", "x1": 0.0, "y1": 0.0, "x2": 100.0, "y2": 50.0}

  3) Círculo ("circle") -> USA SIEMPRE "diameter" (diámetro, NO radio):
     {"kind": "circle", "cx": 0.0, "cy": 0.0, "diameter": 12.0}

  4) Línea ("line") -> Si armas un contorno con líneas, asegúrate de que sea un contorno cerrado continuo:
     {"kind": "line", "x1": 0.0, "y1": 0.0, "x2": 50.0, "y2": 0.0}
